Monks Central, Phase 1 "Connect": live acceptance on WordPress Studio sites
Run: 2026-10-27, Linux (Hyprland), main after ffd3205. Driver: crates/core/examples/acceptance.rs,
which calls the same core API as the app. The browser step is played by the driver: a login cookie
made with `studio wp` for the site's admin, then the site's real consent page, submitted with
"This is my Monks Central app (operator)" ticked when shown. No password, token or cookie is printed.
Site-side checks use `studio wp eval` on CM_MCP_OAuth (grants named "Monks Central" and their
refresh-token rows).

  PASS  connect mc-c in Basic mode (application password)
